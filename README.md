# 📈 Retail Sales Forecasting

## 📌 Project Overview

The **Retail Sales Forecasting** project predicts future retail sales using historical sales data and machine learning techniques. The project helps businesses estimate future demand, identify sales trends, and make data-driven decisions for inventory management and business planning.

This project includes data cleaning, exploratory data analysis (EDA), feature engineering, sales forecasting, SQL analysis, and an interactive Power BI dashboard.

---

# 🎯 Objectives

- Analyze historical retail sales data
- Identify sales trends and seasonality
- Build a machine learning model for sales prediction
- Forecast future sales
- Create an interactive Power BI dashboard
- Generate business insights for decision-making
